AI Starter

Eén commando en je laptop is klaar om met AI te bouwen. Je krijgt Git, Node.js, GitHub CLI en Firebase CLI, precies wat je nodig hebt voor Claude Code, websites op GitHub Pages en apps op Firebase. Je hebt er geen adminrechten voor nodig, dus het werkt ook op een laptop van je werk of opleiding.

Duurt 5 tot 10 minuten. Wat al op je laptop staat, slaat het over. Opnieuw draaien kan altijd.

Windows

Windows 10 en 11
  1. Open PowerShell: klik op Start, typ PowerShell en druk op Enter. Gewoon openen, niet als administrator.
  2. Kopieer dit commando, plak het in PowerShell (rechtermuisknop of Ctrl+V) en druk op Enter:
    irm https://fabianb88.github.io/ai-starter/install.ps1 | iex
  3. Vul je naam en e-mailadres in voor Git. Gebruik het e-mailadres van je GitHub-account.
  4. Kies of je meteen wilt inloggen bij GitHub en Firebase. Dat kan ook later.
  5. Sluit het venster en open een nieuw PowerShell-venster. Draait VS Code al, herstart het dan.

Liever dubbelklikken? Download AI-Starter-Windows.cmd en open het. Krijg je "Windows heeft uw pc beschermd", klik dan op Meer info en Toch uitvoeren. Zie je die knop niet, gebruik dan het commando hierboven.

Mac

macOS (werkt ook op Linux)
  1. Open Terminal: druk op Cmd+spatie, typ Terminal en druk op Enter.
  2. Kopieer dit commando, plak het in Terminal en druk op Enter:
    curl -fsSL https://fabianb88.github.io/ai-starter/install.sh | bash
  3. Vraagt macOS om de Command Line Tools te installeren? Klik op Installeer. Daar zit Git in. Het script wacht tot dat klaar is.
  4. Vul je naam en e-mailadres in voor Git en kies of je meteen wilt inloggen.
  5. Open daarna een nieuw Terminal-venster.

Controleren

Typ in een nieuw venster deze vier commando's. Krijg je bij alle vier een versienummer, dan werkt alles.

git --version; node -v; gh --version; firebase --version

Wat het doet

OnderdeelWaarvoor
GitVersiebeheer van je code. Op Windows inclusief Git Bash, die Claude Code nodig heeft.
Node.js (LTS)Draait JavaScript-tools zoals Claude Code, Firebase CLI en npm-pakketten.
GitHub CLIInloggen bij GitHub, repo's aanmaken en pushen vanaf de terminal.
Firebase CLIApps en websites publiceren op Firebase.
Alleen in je eigen map

Windows: %LOCALAPPDATA%\AI-Starter. Mac: ~/.ai-starter. Het past alleen jouw eigen PATH aan, niet dat van de hele computer.

Officiële bronnen

Downloads komen van github.com, nodejs.org en npmjs.org en worden gecontroleerd met hun SHA-256-controlesom.

Altijd de nieuwste versie

Het script zoekt bij elke installatie de actuele versie op. Er zit geen verouderde kopie in.

Broncode

Bekijk wat het precies doet: install.ps1 (Windows) en install.sh (Mac).

Lukt het niet?

"git" of "node" wordt niet herkend

+

Je gebruikt nog het oude venster. Sluit alle terminals en VS Code en open ze opnieuw. Het nieuwe PATH geldt alleen voor nieuwe vensters.

Een onderdeel geeft een foutmelding

+

Draai het commando gewoon nog een keer. Wat al gelukt is, wordt overgeslagen. Vaak was het een haperende download.

"Dit programma is geblokkeerd door je organisatie"

+

Sommige beheerde laptops staan geen programma's toe buiten de Program Files-map. Daar kan dit script niet omheen. Vraag je IT-afdeling om Git, Node.js, GitHub CLI en Firebase CLI te installeren, of gebruik een eigen laptop.

Inloggen bij GitHub of Firebase later doen

+

Typ in een terminal:

gh auth login --web
firebase login

Lukt het daarna nog niet? Maak een schermafbeelding van het venster en stuur die naar wie je deze link gaf.

Verwijderen

Haalt alles weg wat de AI Starter heeft geïnstalleerd. Je Git-instellingen en logins blijven staan.

Windows (PowerShell)
irm https://fabianb88.github.io/ai-starter/uninstall.ps1 | iex

Of download AI-Starter-Verwijderen.cmd en dubbelklik het.

Mac (Terminal)
curl -fsSL https://fabianb88.github.io/ai-starter/install.sh | bash -s -- --verwijder
