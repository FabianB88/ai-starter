# AI Starter

Eén commando installeert Git, Node.js (LTS), GitHub CLI en Firebase CLI, zonder adminrechten.

Website met uitleg: https://fabianb88.github.io/ai-starter/

| | Installeren | Verwijderen |
|---|---|---|
| Windows (PowerShell) | `irm https://fabianb88.github.io/ai-starter/install.ps1 \| iex` | `irm https://fabianb88.github.io/ai-starter/uninstall.ps1 \| iex` |
| Mac / Linux (Terminal) | `curl -fsSL https://fabianb88.github.io/ai-starter/install.sh \| bash` | `curl -fsSL https://fabianb88.github.io/ai-starter/install.sh \| bash -s -- --verwijder` |

De `.cmd`-bestanden zijn `install.ps1` en `uninstall.ps1` met een kleine kop ervoor, zodat ze te dubbelklikken zijn.
